# ZAMAN — 3D direction prototype

IROVA / Islam Ramadan. Play `/3d/` on GitHub Pages.

Real Three.js/WebGL geometry, perspective orbit/follow camera, articulated stylized child, apartment rooms, animated collidable doors and continuous stairs to a courtyard. Keyboard and touch joystick controls; drag camera; zoom buttons; day/night switch; synthesized audio; local save with separate namespace. Mom and neighbor remember repeat visits.

This is an early playable 3D art-direction and movement prototype, not a realistic life simulator. It does not yet implement full aging, NPC schedules, recorded environmental audio or the previous adventure quest chain.

All assets are procedural code except vendored Three.js 0.160.1 (MIT). No remote runtime dependencies.

Serve this folder or open through GitHub Pages. Tests: `node --test 3d/tests/world.test.js` from repository root.
