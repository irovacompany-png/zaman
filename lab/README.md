# ZAMAN apartment study 0.4

IROVA / Islam Ramadan. Play at /lab/.

A separate architectural prototype, not a completed life simulator.
Three connected rooms with solid partitions and navigable openings; room-aware descriptions, cutaway wall transparency, expanded kitchen/bedroom decoration and independent save key.

Original game and save remain at the repository root. Existing quests/audio/street use the earlier prototype systems. Sound is synthesized, not field recordings.

Run: node --test lab/tests/*.test.js
Seven tests cover room collision, reachability, stair return, and renderer/audio smoke tests.
